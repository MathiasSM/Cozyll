Lists

2024-01-20

Lists come in several flavours.

Bulleted and ordered

  • one item
  • another item
    • a nested item
    • another nested item
  • back to the top level
  1. first
  2. second
  3. third

Ordered lists with a start value

Any number starts the list at that value:

  1. Starts at three.
  2. Then four.

Task lists

Example lists

Mark a list with (@) for an “example” list:

  1. First example.
  2. Second example.

Fancy lists

A letter or roman numeral controls the numbering:

  1. Lowercase letters.
  2. Keep going.
  1. Roman numerals.
  2. Continue.

Line blocks

A line block preserves line breaks:

A line block
keeps each line
   and leading spaces
   on its own line.

Definition lists

A definition rendered as a <dl>.
