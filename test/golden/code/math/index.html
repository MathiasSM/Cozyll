Math

2024-04-02

Mathematics is rendered with MathJax. Inline math sits in a sentence, like \(E = mc^2\) or \(e^{i\pi} + 1 = 0\).

Display math

Display math is set on its own line:

\[\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}\]

Another:

\[\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}\]
