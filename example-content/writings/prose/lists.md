Lists come in several flavours.

## Bulleted and ordered

- one item
- another item
  - a nested item
  - another nested item
- back to the top level

1. first
2. second
3. third

## Ordered lists with a start value

Any number starts the list at that value:

3. Starts at three.
4. Then four.

## Task lists

- [x] a completed item
- [ ] a to-do item

## Example lists

Mark a list with `(@)` for an "example" list:

(@) First example.
(@) Second example.

## Fancy lists

A letter or roman numeral controls the numbering:

a. Lowercase letters.
b. Keep going.

ii. Roman numerals.
iii. Continue.

## Line blocks

A line block preserves line breaks:

| A line block
| keeps each line
|    and leading spaces
|    on its own line.

## Definition lists

Term
:   A definition rendered as a `<dl>`.
