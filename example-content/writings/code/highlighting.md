Fenced code blocks highlight according to their language.

## Haskell

```haskell
main :: IO ()
main = putStrLn "Hello"
```

## Python

```python
def greet(name):
    return f"Hello, {name}"
```

## JavaScript

```javascript
function greet(name) {
  return `Hello, ${name}`;
}
```
