Pipe tables are the most common table syntax.

## Alignment

Alignment is expressed with colons on the separator row:

| Left      | Center     | Right |
| :-------- | :--------: | ----: |
| alpha     | beta       | gamma |
| one       | two        | three |

## Captions

A table can carry a caption:

| Name   | Value |
| ------ | ----- |
| alpha  | 1     |
| beta   | 2     |

: A captioned pipe table.
